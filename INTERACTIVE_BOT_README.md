# Интерактивный Telegram-бот для Zabbix NT

## Обзор

Интерактивный бот позволяет пользователям запрашивать информацию о метриках Zabbix через Telegram по IP-адресу хоста.

## Возможности

- 🔍 Поиск хоста по IP-адресу
- 📊 Просмотр доступных метрик с пагинацией
- 📈 Получение графиков с водяными знаками
- ⌨️ Интерактивная клавиатура для навигации
- 🔄 Поддержка нескольких ботов одновременно

## API Endpoints

### Запуск интерактивного бота

```bash
POST /api/znt/interactive/start/{bot_id}
```

Запускает интерактивного Telegram-бота для просмотра метрик Zabbix.

**Параметры:**
- `bot_id` (int) - Идентификатор бота в базе данных

**Ответ:**
```json
{
  "status": "success",
  "detail": "Интерактивный бот @mybot запущен"
}
```

### Остановка интерактивного бота

```bash
POST /api/znt/interactive/stop/{bot_id}
```

Останавливает работающего интерактивного бота.

**Параметры:**
- `bot_id` (int) - Идентификатор бота

**Ответ:**
```json
{
  "status": "success",
  "detail": "Интерактивный бот @mybot остановлен"
}
```

### Статус интерактивных ботов

```bash
GET /api/znt/interactive/status
```

Получение статуса всех запущенных интерактивных ботов.

**Ответ:**
```json
{
  "total": 2,
  "bots": [
    {
      "bot_id": 1,
      "status": "running",
      "updater_active": true
    }
  ]
}
```

## Использование в Telegram

### Команды бота

- `/start` - Начало работы
- `/help` - Справка по командам
- `/exit` - Сброс текущего состояния

### Рабочий процесс

1. Отправьте боту IP-адрес хоста (например, `192.168.1.100`)
2. Бот найдет хост в Zabbix и покажет список доступных метрик
3. Выберите нужную метрику из предложенных кнопок
4. Бот отправит график и текущее значение метрики
5. Используйте кнопки навигации `<< Предыдущая` / `Следующая >>` для переключения страниц
6. Нажмите `Выход` для возврата к вводу нового IP

## Конфигурация

Настройки берутся из основного файла `znt.cfg`:

### Zabbix настройки
```ini
[zabbix]
url=http://your-zabbix-server/
login=Admin
password=your_password
connect_timeout = 3
```

### Настройки графиков
```ini
[znt.settings]
zabbix_graph = True
zabbix_graph_period_default = 3600
watermark = True
watermark_label = Your Company Name
```

## Пример использования через API

```python
import requests

# Запуск бота
response = requests.post('http://localhost:8081/api/znt/interactive/start/1')
print(response.json())

# Проверка статуса
response = requests.get('http://localhost:8081/api/znt/interactive/status')
print(response.json())

# Остановка бота
response = requests.post('http://localhost:8081/api/znt/interactive/stop/1')
print(response.json())
```

## Отличия от стандартного режима уведомлений

| Характеристика | Уведомления (ZNT) | Интерактивный бот |
|---------------|-------------------|-------------------|
| Режим работы | Push-уведомления | On-demand запросы |
| Инициатор | Zabbix (триггеры) | Пользователь Telegram |
| Данные | Информация о событиях | Текущие метрики хоста |
| Графики | Прикладываются к алертам | По запросу пользователя |

## Безопасность

- Бот использует те же учетные данные Zabbix, что и основной сервис
- Рекомендуется создавать отдельного пользователя Zabbix с ограниченным доступом
- Прокси поддерживается через существующую систему прокси ZNT
